# UX Design

## User Types

### Admin

* Manage users
* View all prompts
* Configure available AI models

### Registered User

* Create prompts
* Edit prompts
* Version prompts
* Generate images
* Compare models
* Upload images for prompt generation

## Application Pages

### Home Page

* Welcome message
* Navigation menu
* Quick access to features

### Prompt Library

* View saved prompts
* Search and filter prompts
* Edit or delete prompts

### Create Prompt Page

* Create new prompts
* Add tags and categories

### Image Generation Page

* Select model
* Enter prompt
* Generate image

### Model Comparison Page

* Compare outputs from multiple models

### Image-to-Prompt Page

* Upload image
* View generated prompt suggestions

### Account Page

* User profile
* Saved prompts
* Generated image history
